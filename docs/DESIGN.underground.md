# DESIGN（裏画面）— NAGATA UNDERGROUND

> 対象: `/casino/*`（`/casino/enter` を含む）。表画面「灼熱の青春」用の DESIGN は未作成（spec.md 未決定事項）。
> 出典: Claude Design「体育祭サイト モック v3 賭け画面」。トークンの実体は `src/app/globals.css`（`@theme` と `.ug-*` クラス）。

## コンセプト
当日の生徒が締切・残高を読み、予想対象と賭け金を少ないスクロールで選べる端末にする。

### 2026-10-01 表示密度
- 色・フォント・金属筐体と緑液晶の世界観は継承。拡大縮小で文字やタップ領域を削らず、枠と余白を減らす。
- 寸法の実体は globals.css の `--ug-*`。筐体幅760px、最大高さ820px、液晶余白12px、枠6px、操作台間隔8px、キー44px。
- 幅700px以上は予想対象とBET SLIPを2列、それ未満は縦。低い画面でも液晶と操作台を残す。safe-areaを確保。
- 入力16px以上、本文のぼかしを除去する。
「カジノ風の Web サイト」ではなく、**体育祭システムの裏側に接続された古い賭博端末を操作している**体験。
画面は 3 層に分ける（コンポーネントもこの境界で分割する）。

| 層 | コンポーネント | 役割 |
|---|---|---|
| CABINET（筐体） | `components/underground/Cabinet.tsx` | 塗装金属パネル。PWR/LINK LED・銘板・SOUND スイッチ・CREDIT メーター |
| LCD（液晶） | `components/underground/Lcd.tsx` | 緑単色液晶。タブ・時計・同期表示・本文・ステータス行 |
| HARDWARE CONTROLS | `components/underground/HardwareControls.tsx` | F1〜F4・BACK・状態 LED・ENTER |

LCD 内には立体的な Web ボタンを描かない。選択は反転表示（`.ug-sel`）・`▶`/`>` カーソル・枠線で表す。

## 表現
- 周辺減光・走査線（`.ug-lcd::before/::after`）、像の甘さ（本文 `blur(.15px)`）
- RGB ずれは主要表示のみ（`.ug-rgb`：競技番号・締切）
- カーソル移動時に走査線が 1 回走る（`.ug-row[data-cursor]`）。hover で拡大・影は使わない
- オッズ更新時は数値だけ短く点滅（`.ug-flash` 420ms）。自動・手動の同期直後は LCD 右上の `LIVE` が約 0.9 秒 `UPDATE`（`lcd-hi`）に変わる
- CREDIT メーターの「8,888 C」焼き付き。残高が変わると 600ms で数字を送って新しい値に着地する（`Cabinet.tsx` の `useRollingCounter`）
- 液晶パネルの輝度ムラ（`.ug-lcd` の背景に薄い明暗 4 か所）と、走査線入りの溝のスクロールバー
- 締切済み（CLOSED）の Market 行は取り消し線＋減光。NEXT の札は締切 60 秒前から赤
- 的中演出（HIT）：結果演出のリールが止まって的中していたら、液晶全面を暗転させて「▲ HIT ・ 的中 ▲」・払戻額（Anton 大）・実効倍率・的中した対象を 3.4 秒出す（`bet/WinFx.tsx`、`.ug-win*`）。紙吹雪は Canvas 2D で液晶の内側にだけ降らせる（ライブラリ不使用）。タップ・任意のキー・ENTER で閉じ、下の結果演出はそのまま残る
- 角丸・カードシャドウ・グラデーションの多用・常時グリッチは禁止

## モーション・音
- 0.1〜0.5 秒程度、`steps()` 系の機械的な切替。`prefers-reduced-motion` で無効化（紙吹雪・メーターの数字送りも止める）。的中演出は reduce でも動きを止めた静止表示で 3.4 秒出す（拡大・点滅・フェードは無し）
- 効果音は WebAudio の短いビープ（100〜300ms）。初期はミュート、筐体の SOUND スイッチで切替。音なしでも情報は欠落しない

## 操作
| 操作 | 画面内 | キーボード |
|---|---|---|
| 選択 | 行・枠をタップ | ↑ ↓ |
| 決定 | ENTER ボタン / BET ボタン | Enter |
| 戻る | BACK / ‹ EVENTS | Esc |
| 同期 | LCD 右上の `[R] SYNC` | R |
| セクション | F1〜F4 | F1 |

タップ領域は 44px 以上。

### 2026-09-12 演出の拡張
既存の緑単色液晶・等幅ログ・金属筐体のトークンを維持。入場時はモックv3の起動ログと進捗バーを表示する。音はWebAudioによるオリジナル短調アルペジオと低音を追加し、SOUNDで操作音と一緒に切替。初期OFF、バックグラウンドでは停止。DEVパネルも液晶トークンから導出する。
- 的中時は既存の紙吹雪・払戻額表示に上昇音と4音のファンファーレを追加。SOUNDがOFFなら無音。

### 2026-09-12 筐体と液晶の分離
黒いモニター枠（ug-screen-bezel）と塗装された操作台（ug-control-deck）を別の面として構成する。走査線・発光・起動・的中は液晶内のみ。モックv3のBOOT全19行、入力46ms/文字・出力18ms/チャンク、初期待機1000ms、行末の待機、末尾の█、下端からの積み上げを移植した。起動後の接続表示も同じ文字送りとバーで表示する。認証は実際のユーザーID・パスワードを入力するサーバー認証を使う。初回は NEW ACCOUNT でユーザーID・パスワード・必須ニックネームを設定する。既存セッションでも起動表示を経由する。
