# デザイン仕様

> 対象: 体育祭サイト「長田すぎて滅！青春爆裂愛してる」
> ステータス: Draft 1
> 目的: 表画面と裏画面を意図的に断絶させ、「表では公式体育祭が進行し、その裏では非公式な賭場が動いている」という二重世界を成立させる。

---

## 1. デザインコンセプト

本サイトは、同一の体育祭データを扱いながら、**表画面と裏画面で完全に異なる世界観を提示する**。

### 表画面

- 役割: 体育祭の公式情報サイト
- 主な利用者: 全校生徒・教員・保護者など
- 想定: 大半のユーザーは表画面のみを利用する
- 印象: 明るい、熱い、青春、公式、勢いがある
- キーワード: **灼熱 / 青春 / 応援旗 / 太陽 / 爆発 / 手描き / 体育祭**

### 裏画面

- 役割: 一部のユーザーだけが発見・利用する非公式の隠し賭場
- 主な利用者: 隠し入口を知っている生徒
- 印象: 暗い、閉鎖的、秘密、機械的、危うい、深夜
- キーワード: **地下 / ネオン / 電光掲示板 / 遊技場 / スロット / 賭場 / MEMBERS ONLY / 深夜**

### 最重要原則

> **データは共有するが、世界観は共有しない。**

表と裏で同じ競技・得点・結果を参照しても、見せ方・語彙・配色・タイポグラフィ・音・画面構成は別物とする。

## 2. 表裏分離のルール

### 2.1 表画面から裏画面を感じさせない

通常閲覧では、カジノ・ベット・オッズ・チップ・クレジット等の要素を一切見せない。

禁止例:

- トップページに「Casino」「BET」等の文言を出す
- カジノを連想させるトランプ・チップ・ルーレットを表画面に置く
- 表画面のナビゲーションから裏画面へ直接リンクする
- ポイント残高を表画面の主要情報として強調する

### 2.2 裏画面では表画面のUIを引き継がない

裏画面では以下を原則として消す。

- 表画面のヘッダー
- 表画面のグローバルナビゲーション
- 表画面のフッター
- 表画面の色・カードデザイン
- 表画面の「公式サイト」らしいUI

裏画面専用のレイアウトを使用する。

### 2.3 同じデータでも語彙を変える

| 表画面 | 裏画面 |
|---|---|
| 種目 | RACE / GAME / MARKET |
| 女子6×100mリレー | RACE 03 / GIRLS RELAY |
| 男子スウェーデンリレー | RACE 04 / SWEDEN RELAY |
| 男女混合リレー | RACE 05 / MIXED RELAY |
| 現在順位 | STANDINGS |
| 得点 | SCORE / PT |
| 予想受付中 | MARKET OPEN |
| 締切 | CLOSE |
| 結果確定 | SETTLED |
| ポイント | CREDIT / CHIP |
| 倍率 | ODDS |

※「裏で同じ体育祭を別の意味で観測している」感覚を出す。

## 3. 表画面デザイン

### 3.1 テーマ

**「灼熱の青春」**

体育祭の公式サイトとして十分に読みやすく、実用性を優先しつつ、イベントらしい勢いを持たせる。

### 3.2 視覚要素

- 赤〜オレンジ〜黄色を中心とした高彩度の暖色
- 太陽、集中線、旗、紙、テープ、手描き線
- 極太ゴシックと筆文字の組み合わせ
- 白背景または明るい暖色背景を主体にする
- 見出しは強く、本文は読みやすさを優先する

### 3.3 UIの優先順位

表画面は演出よりも「当日に使えること」を優先する。

1. 現在進行中の競技
2. 次の競技
3. プログラム
4. 得点・順位
5. ログイン / マイページ
6. 招集案内

### 3.4 アニメーション

- ページ遷移: 軽快で短い
- 得点更新: カウントアップ
- 現在競技の切り替え: スライドまたはフラッシュ
- 大規模な演出は行わない

表画面では、閲覧の邪魔になる長いアニメーションや音を使用しない。

## 4. 隠し入口

### 4.1 基本方針

裏画面への入口は、**通常利用者には意味を持たないが、知っている人は再現可能な方法**にする。

「偶然見つけてもよい」「口コミで共有できる」の両方を成立させる。

### 4.2 推奨案

トップページ下部の「79」など、体育祭に自然に存在する数字を秘密入口とする。

例:

- フッターの「79」を5回タップ
- 校章の一部を一定回数タップ
- 特定箇所を長押し

現時点の第一候補:

> **「79」を5回タップ**

### 4.3 発見難易度

- 通常利用では気づかなくてよい
- 知人から「79を5回押せ」と聞けば迷わず入れる
- 複雑な謎解きは要求しない
- ランダム条件は使わない

### 4.4 発火後の遷移演出

隠し入口の操作完了後、即座に普通のページ遷移を行わない。

推奨シーケンス:

1. 表画面の音が消える
2. 画面が一瞬停止
3. 暗転
4. `SYSTEM ERROR` または短いノイズ
5. `AUTHORIZED PERSONNEL ONLY`
6. ネオン看板点灯
7. `NAGATA UNDERGROUND` / `長田大遊技場`
8. `/casino/enter`へ遷移

全体は2〜4秒程度を目安とする。

## 5. 裏画面デザイン

### 5.1 テーマ

**「深夜の隠れ賭場 / 長田大遊技場」**

ラスベガスの高級カジノをそのまま再現するのではなく、以下を混ぜた架空の地下遊技場とする。

- 日本のパチスロ
- 昭和〜平成初期のゲームセンター
- ネオン看板
- 電光掲示板
- 地下施設
- カジノゲーム
- 体育祭の得点・競技情報

### 5.2 印象

目指すもの:

- 非公式
- 隠れている
- 少し危うい
- 閉店後・深夜
- 機械の光だけが点いている
- 知っている人だけがいる

避けるもの:

- 高級ホテルのラウンジ風
- 洗練されすぎた欧米オンラインカジノ
- 緑フェルト＋金だけの典型的カジノUI
- 表画面の青春感をそのまま暗色化しただけのデザイン

## 9. `/casino/enter` 入場画面

### 9.1 役割

通常のログインページではなく、**秘密施設の認証端末**として演出する。

### 9.2 初回

通常の「パスワードを設定してください」ではなく、以下の表現を使用する。

```text
MEMBERSHIP REGISTRATION
ACCESS KEYを登録
```

または

```text
会員鍵を登録する
```

### 9.3 2回目以降

```text
MEMBER AUTHENTICATION
ACCESS KEY
[________________]

ENTER
```

### 9.4 エラー

普通のフォームエラーではなく短い端末表示にする。

```text
ACCESS DENIED
KEY INVALID
```

ただし、ユーザーが原因を理解できる日本語補助文は残す。

## 11. Market画面

### 11.1 基本レイアウト

競技ごとに専用の「卓」へ入るイメージにする。

```text
RACE 05
MIXED RELAY

MARKET OPEN                 CLOSE 03:42

1組     2.40x      ████████
2組     3.80x      █████
3組     2.10x      █████████
4組     5.30x      ███
...

BET AMOUNT
[ 100 ] [ 300 ] [ 500 ] [ CUSTOM ]

[ PLACE BET ]
```

### 11.2 チーム表示

- 8チームを同一形式で並べる
- オッズを最も大きく見せる
- 人気度をバー等で補助表示してよい
- 色だけで識別しない

### 11.3 Bet確定

ボタン押下後に即終了せず、短い確認演出を入れる。

```text
BET ACCEPTED
RACE 05 / 3組
500 C
```

1秒程度でよい。

## 12. Market状態表現

### OPEN

- 赤または金
- カウントダウン表示
- 操作可能

### CLOSED

```text
MARKET CLOSED
集計中
```

- Bet操作を完全停止
- Oddsを固定

### SETTLED

```text
WINNER
3組

PAYOUT 2.18x
+1,090 C
```

結果確定時は裏画面で最も強い演出を使用してよい。

## 13. 当選・結果演出

### 13.1 通常当選

- 数字カウントアップ
- 電光掲示板切替
- チップ音
- 軽いネオンフラッシュ

### 13.2 大きな配当

一定以上の配当時のみ特別演出を許可する。

- スロットリール
- 777
- JACKPOT
- 紙吹雪
- 強い効果音

### 13.3 外れ

過度に煽らない。

```text
NO HIT
NEXT GAME
```

程度に留める。

## 14. Credit / 借入・返済画面

現行仕様上の借入・返済機能は保持するが、UIでは金融サービスのように見せず、**地下賭場の内部クレジット**として表現する。

### 表記

- 所持ポイント → `CREDIT`
- 借入 → `ADVANCE CREDIT`
- 返済 → `RETURN CREDIT`
- 借金額 → `OUTSTANDING`

日本語補助表示も併記する。

例:

```text
CREDIT        2,450 C
OUTSTANDING     500 C
```

機能上重要な金額・利子・返済条件は演出で隠さず明示する。

## 16. モーション設計

### 表画面

- 速い
- 明るい
- 0.15〜0.4秒程度
- spring系モーション中心

### 裏画面

- 少し重い
- 機械的
- 0.2〜0.8秒程度
- ネオン点灯、数字切替、リール、フリッカー

### 禁止

- 常時激しく点滅する背景
- 読めないほどのグリッチ
- 主要操作を毎回2秒以上待たせる演出
- スクロールに追随して常時大きく動く背景

---

## 17. サウンド設計

### 表画面

原則無音。

必要な場合でも自動再生しない。

### 裏画面

サウンドは重要な世界観要素として使用する。

候補:

- 小さな電子ノイズ
- 機械式ボタン
- コイン / チップ
- リール停止音
- 電光掲示板切替
- 当選音

### ルール

- 初回はミュートを基本とする、または明確にON/OFF可能にする
- サウンド切替を画面内に常設
- 操作音は100〜300ms程度
- BGMは使用する場合でも非常に小さくする

---

## 18. スマートフォン対応

生徒の主要端末をスマートフォンと想定する。

### 表画面

- 片手操作
- 下部ナビゲーションも検討
- 最重要情報は1画面目に置く

### 裏画面

デスクトップのカジノ卓を縮小するのではなく、モバイル専用レイアウトにする。

推奨:

```text
[NAGATA UNDERGROUND]
[CREDIT 2450C]

[NEXT RACE]
[MIXED RELAY]
[CLOSE 03:42]

[1組 2.4x]
[2組 3.8x]
[3組 2.1x]
...

[BET]
```

---

## 19. アクセシビリティ

世界観を優先しても以下は維持する。

- 本文コントラストを確保
- 色だけで勝敗・状態を表現しない
- タップ領域44px程度以上
- `prefers-reduced-motion` 対応
- 効果音OFFでも情報が欠落しない
- 点滅演出は短時間かつ低頻度
- 入力エラーを演出だけで伝えない

---

## 20. 実装上のコンポーネント分離

表と裏の共通UIコンポーネント化を過剰に行わない。

### 共有してよいもの

- データ取得ロジック
- 型
- APIクライアント
- 日付・数値フォーマッタ
- 認証状態

### 原則共有しないもの

- Header
- Navigation
- Card
- Button visual
- Typography
- Background
- Dialog visual
- Loading animation

表裏で同じ `Button` にテーマだけ当てる設計より、必要なら `OfficialButton` / `UndergroundButton` のように分ける。

## 21. ルーティングと世界観

```text

/login
/me
/ranking
/admin

/casino/enter

```

`/casino/*`に遷移した後はOfficialのナビゲーションを表示しない。

表へ戻る操作を用意する場合も、通常の「ホームへ戻る」ではなく、世界観に合わせて以下のような表現を検討する。

```text

RETURN TO SURFACE
```

## 23. やってはいけないデザイン

### 表

- カジノを匂わせる
- 情報より演出を優先する
- 可読性の低い筆文字を本文に使う

### 裏

- 典型的な緑フェルトだけのオンラインカジノ
- ラスベガス風の高級ホテルデザイン

## 24. デザイン受け入れ条件

### 表画面

- [ ] 初見ユーザーがカジノの存在を推測しにくい
- [ ] 体育祭公式サイトとして自然に利用できる
- [ ] スマホでプログラム・得点・招集情報へ短時間で到達できる
- [ ] 明るく熱量のある体育祭らしい世界観になっている

### 隠し入口

- [ ] 通常利用では目立たない
- [ ] 方法を知っていれば再現可能
- [ ] 発火後、表から裏へ世界が切り替わったことが明確に分かる

### 裏画面

- [ ] 表画面と同一サイトに見えないほど視覚言語が変わっている
- [ ] 同じ体育祭データが別の意味・語彙で表現されている
- [ ] NEXT RACE / CLOSE / ODDS / CREDITが即座に認識できる
- [ ] Market一覧ではなく「次の勝負」が中心になっている
- [ ] スマートフォンで主要操作が片手で行える
- [ ] アニメーション・音をOFFにしても操作できる

## 26. 一文での最終定義

> **昼の表では、全校生徒が「体育祭」を見ている。夜の裏では、一部の人間だけが同じ体育祭を「市場」として見ている。表と裏はデータだけでつながり、体験としては断絶している。**
