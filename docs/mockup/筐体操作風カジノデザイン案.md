# 筐体操作風カジノデザイン案

## 1. コンセプト

裏画面は「Webサイト上のカジノUI」ではなく、**ブラウザ上で架空の賭博端末を操作している体験**として設計する。

表画面の公式体育祭サイトとは視覚・語彙・操作体系を明確に分離し、裏側にのみ存在する「NAGATA UNDERGROUND / 長田大遊技場」の専用端末という設定にする。

### 目標イメージ

- 古い業務用液晶端末
- CRTモニタの残像・走査線
- VFD/7セグ表示
- 昭和〜平成初期のゲーム筐体
- 競馬・パチスロ・場外端末の無機質さ
- 地下賭場の違法感・閉鎖感

比率の目安：

- CRT的表現：40%
- 古いLCD/VFD：30%
- 業務用賭博端末：20%
- 現代Web UI：10%

重要なのは「グリッチ系Webデザイン」にすることではなく、**本当に古い端末を操作しているように見せること**。

---

## 2. 基本構造

裏画面全体を次の3層で構成する。

```text
BODY
└─ TERMINAL CABINET
   ├─ LCD DISPLAY
   │   ├─ Header
   │   ├─ Main content
   │   └─ Status line
   │
   └─ HARDWARE CONTROLS
       ├─ Function keys
       ├─ Back
       ├─ Enter
       └─ Indicator LEDs
```

### 原則

**LCD内部には原則として立体的な物理ボタンを描画しない。**

画面内の操作対象は以下に限定する。

- 反転表示
- `>` カーソル
- 点滅カーソル `_`
- 枠線
- ハイライト
- 選択中の走査線

実際の「押す」操作は筐体側のハードウェアコントロールで行う。

## 3. PC版レイアウト

PCでは、ブラウザ内に筐体そのものを再現する。

```text
┌─────────────────────────────────────┐
│   NAGATA UNDERGROUND TERMINAL 79    │
│ ┌─────────────────────────────────┐ │
│ │                                 │ │
│ │          LCD DISPLAY            │ │
│ │                                 │ │
│ │   RACE 05                       │ │
│ │   BOU-HIKI                      │ │
│ │   CLOSE 01:01                   │ │
│ │                                 │ │
│ │   > PRESS ENTER TO OPEN         │ │
│ │                                 │ │
│ └─────────────────────────────────┘ │
│                                     │
│   [ ● ENTER ]   [ ◀ BACK ]          │
│                                     │
└─────────────────────────────────────┘
```

### 画面内

- RACE番号
- 競技名
- 締切時間
- オッズ・プール
- 選択中Market
- システムメッセージ

### 画面外

- ENTER
- BACK
- F1〜F4
- 状態LED
- CREDIT表示（必要なら独立表示器）

## 4. スマホ版レイアウト

スマホでは画面自体を携帯端末の筐体として扱う。

```text
┌──────────────────┐
│                  │
│ LCD DISPLAY      │
│                  │
├──────────────────┤
│ [BACK]    [ENTER]│
└──────────────────┘
```

### 方針

- 上部〜中央：LCD表示
- 下部固定：物理操作風ボタン
- F1〜F4は横スクロールまたは2段配置
- PC版よりも筐体縁は簡略化
- 画面内タップでも選択は可能にするが、最終決定はENTERボタンで行う

---

## 5. ナビゲーション

通常のWebナビゲーションは使用しない。

### 例

```text
[F1] MARKET
[F2] CREDIT
[F3] HISTORY
[F4] RANK
```

PCでは実キーボードにも対応できる。

```text
F1 = MARKET
F2 = CREDIT
F3 = HISTORY
F4 = RANK
ESC = EXIT
ENTER = SELECT
↑ ↓ = MOVE
```

画面上の現在位置は、タブ下線ではなく以下のように表現する。

```text
> F1 MARKET
  F2 CREDIT
  F3 HISTORY
  F4 RANK
```

または該当行のみ反転表示する。

## 6. Market一覧の操作

通常のカードUIは使わず、端末リスト風にする。

```text
>05 BOU-HIKI
    MARKET OPEN · POOL 6,800 C

 06 KIBASEN
    MARKET OPEN · POOL 5,100 C

 *  OVERALL WINNER
    MARKET OPEN · POOL 23,000 C
```

### Hover時

一般的な `scale(1.03)` や影の拡大は禁止。

代わりに以下を使用する。

- `>` カーソルが移動
- 選択行に走査線が1回走る
- 文字が一瞬だけ欠ける
- ENTER LEDが点灯
- 軽いクリック音またはリレー音

### Hover例

```text
0ms   通常
30ms  横方向の発光線
70ms  発光線が右へ移動
120ms 文字が1フレーム乱れる
150ms 選択状態で安定
```

---

## 7. ENTER操作

Marketを開く操作は、画面内の巨大ボタンではなく筐体側のENTERで行う。

画面側には、

```text
> MARKET 05 READY
> PRESS [ENTER]
```

とだけ表示する。

### ENTERボタン

- 平常時：暗赤色
- 選択可能時：弱く点灯
- Hover/Focus時：明るく点灯
- 押下時：2〜3px沈む
- 決定時：クリック音＋画面遷移

### LED

ENTER横に小さな状態LEDを置く。

- 消灯：操作不可
- 黄：選択可能
- 赤：締切直前
- 緑：認証成功・確定

## 8. ディスプレイ表現

## 8.1 黒を均一にしない

画面中央をわずかに明るくし、周辺を暗くする。

```css
background:
  radial-gradient(
    ellipse at center,
    rgba(45, 18, 14, .20) 0%,
    rgba(10, 5, 4, .65) 65%,
    #020202 100%
  );
```

## 8.2 走査線

```css
.screen::after {
  content: "";
  position: fixed;
  inset: 0;
  pointer-events: none;
  background:
    repeating-linear-gradient(
      0deg,
      rgba(255,255,255,.025) 0px,
      rgba(255,255,255,.025) 1px,
      transparent 1px,
      transparent 3px
    );
}
```

### 注意

強すぎる走査線は可読性を壊すため、常時は非常に薄くする。

---

## 9. RGBズレ・色収差

主要表示のみに適用する。

対象例：

- RACE 05
- CLOSE 01:01
- CREDIT
- NAGATA UNDERGROUND
- MARKET OPEN

```css
text-shadow:
  -1px 0 rgba(255, 0, 0, .35),
   1px 0 rgba(0, 180, 255, .25),
   0 0 5px rgba(255, 235, 210, .25);
```

全テキストに適用しない。

---

## 10. フォーカスの甘さ・ゴースト

主要文字に微小なblurを入れる。

```css
filter: blur(.15px);
```

同一文字を疑似要素で薄く重ね、1px程度ずらして残像を作る。

目的：

- 高解像度Web感を減らす
- 古いLCD/CRTらしい像の甘さを出す

---

## 11. 焼き付き・残像

固定表示にはごく薄い焼き付きを残す。

例：

```text
CREDIT
1,500 C
```

の背後に、ほぼ見えない程度で

```text
CREDIT
8,888 C
```

を残す。

対象：

- CREDIT
- NAVIGATION
- MARKET番号
- STATUS LINE

これにより「以前から使われ続けている端末」という時間軸を作る。

## 12. 色設計

色数は少なくする。

### 基本

- Background：黒〜茶黒
- Main：アンバー
- Secondary：Dirty White
- Warning：赤
- System：シアン
- Success：緑

### 役割

```text
通常文字       Dirty White
主要数字       Amber
選択           Amber
OPEN           Amber / Green
CLOSED         Dark Red
警告           Bright Red
System情報     Cyan
```

シアンは「システム側の情報」に限定して使う。

## 13. フォント役割

### DISPLAY

対象：

- RACE 05

特徴：極太Condensed。

### TERMINAL

対象：

## 14. グリッチの扱い

常時グリッチは禁止。

20〜60秒に一度程度、50〜100msだけ画面異常を出す。

例：

```text
NAGATA UNDERGRO_ND
      RACE  05
     RACCE 05
────────────
```

すぐ正常へ戻す。

「グリッチ演出」ではなく「端末の調子が少し悪い」という程度にする。

---

## 15. ページ遷移

通常のフェードは使わない。

### Market入場

```text
0ms    現在画面
80ms   画面が縦方向に圧縮
160ms  中央に発光線1本
250ms  黒
350ms  CONNECTING...
500ms  一瞬ノイズ
650ms  次画面
```

CRTの電源OFF/ONを模した演出。

### 強い遷移を使う箇所

- Casino初回入場
- Market入場
- 結果発表
- 最終ランキング

### 軽い遷移

戻る・タブ切替は150ms前後の走査線または横ワイプにする。

## 16. `/casino/enter` の演出

カジノ入口は認証端末として見せる。

```text

NAGATA SYSTEMS
PRIVATE NETWORK

CONNECTING TO NODE 79...
████████████░░░

CONNECTION ESTABLISHED

MEMBER ID:
> ________

```

認証成功：

```text

```

その後、画面異常→暗転→NAGATA UNDERGROUNDへ遷移。

## 17. カーソル

PC版のみ独自カーソルを使用可能。

候補：

- `+`
- 十字照準
- L字カーソル

移動時に1〜2フレームだけ残像を出す。

スマホでは無効。

## 18. 音設計

音は世界観に直結するため、過剰に使わない。

### 使用候補

- リレークリック
- メカニカルスイッチ
- 古い端末のビープ
- コイン/チップ音
- 軽いブラウン管ノイズ
- 認証成功音
- 警告ブザー

### 原則

- Hoverだけで毎回大音量を出さない
- ENTER決定時に明確な音
- ページ遷移と音を同期
- ミュート操作を常設

---

## 19. パネル設計

整いすぎたWebカードを避ける。

### 避ける

```text
┌────────────────────┐
│                    │
└────────────────────┘
```

### 推奨

```text
[05]-------------------------
```

または角を欠けさせる。

```text

 │                    │
 │                    │
 └───────────────
```

### 禁止

- 大きなborder-radius
- 浮遊するカードシャドウ
- SaaS風ガラスカード

## 20. 操作ルール

### 選択

- Mouse Hover
- ↑ ↓
- タップ

### 決定

- ENTERボタン
- Enterキー

### 戻る

- BACKボタン
- ESCキー

### セクション

- F1〜F4

この操作体系を全ページで統一する。

---

## 21. デザイン上の禁止事項

- LCD内に立体的なWebボタンを置かない
- Hoverでカードを拡大しない
- Material Design風UIにしない
- グラデーションを大量使用しない
- グリッチを常時表示しない
- ネオンを全要素に使わない
- すべての文字を高彩度にしない
- 高級ラスベガス風だけに寄せない
- 画面を完全に読みづらくしない

---

## 22. デザインの完成イメージ

ユーザーが感じるべきことは、

> 「カジノ風にデザインされたWebサイトを開いた」

ではなく、

> **「体育祭の公式システムの裏側に接続された、正体不明の古い賭博端末を操作している」**

である。

そのため、デザインの中心は装飾ではなく、

- 表示装置
- 操作装置
- 反応速度
- ノイズ
- 音
- 遷移
- 入力方式

を一貫させることに置く。
