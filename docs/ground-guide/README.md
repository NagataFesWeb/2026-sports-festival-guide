# 3D集合案内の資料と連携

2026-09-12。R8.zipの演技台帳とユーザー提供航空写真から、集合・入退場の情報だけを整理した。氏名・担当者・名簿・元のWord全文は保管しない。ZIPは一時フォルダに展開して参照した。

## 使い方

`/me?id=<学籍番号>` の「自分の出場競技」で「集合場所・移動を3Dで確認」を押すと、その競技・出場枠の案内が同じページ内で開く。「種目別 招集案内」は、個人情報を持たない競技全体の3D集合区分図を表示する。集合時間・持ち物など既存の実行委員情報は引き続き表示する。

3D案内は静的出場データだけを参照し、DBや外部地図APIへのアクセスを追加しない。`/me` の既存の招集時刻・名簿などは従来どおりDB由来だが、「自分の出場競技」の3Dはその応答を待たずに開ける。別の学籍番号へ変更すると所属・出場枠も更新する。

出発地点の初期値は自分の組の生徒席。追加図に合わせ、1年は左側の下から上へ1〜8組、2年は奥の左から右へ1〜8組、3年は右側の上から下へ1〜8組。テントはトラックと同心の外周円弧に沿って配置し、長辺を接線方向に回転する。奥の直線部分は横一列。棟数と大きさは模式表現とする。2026-09-12のユーザー確認により、集合・競技位置へのトラック横断を許可し、外周迂回をやめて直接の矢印を表示する。

個人用の `GroundGuide` は全体の集合区分を常に表示し、該当する区分をピンクの実線と「自分の区分」で強調する。他の区分は青の破線。移動矢印とGPSは個人用のみ。全体用の `GroundOverview` は出発地・学年組・走順入力・GPS・個人の矢印を表示しない。

`GroundGuide` の `embedded` を指定するとページ見出し・学籍番号の再入力・別ページへのリンクを省略する。`initialStudentId`・`initialEvent`・`initialSlot` を渡し、個人の走順を反映する。1つの出場カードだけを展開し、閉じるとGPS監視を解除する。独立した `/ground-guide` も引き続き利用できる。

## モデル

- 実体：`src/lib/ground-guide/model.ts`。3D頂点・面・素材からグラウンド、トラック8コース、テント、指揮台、競技用具を生成する。
- ビューア：3D頂点を回転・投影してSVGに描画。追加依存なし。上下を反転した平面画像を表示するだけの仕組みではない。
- 再利用用：`public/models/nagata-ground.gltf`（glTF 2.0・バッファ内蔵）。`node scripts/generate-ground-model.mjs` で再生成できる。
- 画面の「3Dモデル保存」は選択中の競技配置をglTFで出力する。案内の文字・矢印はビューア側の重ね表示で、glTFには含めない。
- 寸法・通路・テント位置は概略。実測・測量モデルではなく、モデル座標を距離表示に使わない。
- 配色・文字・枠・操作部は `../DESIGN.festival.md` の既存トークンを継承。別のデザイン体系を作らない。

## 向き・GPS

ユーザー確認：航空写真の上（道路・校舎側）が本部側。モデルは本部を下に揃え、写真から180度回転した向き。大縄配置図の東＝左、西＝右に合わせる。玉入れの原図だけは指揮台が上なので、180度回して他の図と揃える。

階段のユーザー提供座標：緯度34.669162、経度135.143414。モデル上の階段位置は概略。学校のGoogleマップ施設ピンをグラウンド中心や階段位置として使わない。

GPSはボタンを押して許可した場合だけwatchPositionで取得する。精度20m超・30秒超の古い位置は矢印の起点に使わない。位置合わせ前は階段への直線距離を表示するだけで、誤った場所に現在地を描かない。本部前外周中央と対向する生徒席側外周中央の緯度・経度を入力すると回転・縮尺が決まり、現在地からの矢印が更新される。2点は会場近傍・距離30〜180mで検証。設定と現在地はReactの画面内メモリのみ。GPS停止・手動出発地選択・画面離脱で監視を解除する。HTTPSまたはlocalhostが必要。

GPS範囲外・拒否・取得失敗・精度不足は手動選択に戻る。位置合わせは未実測であり、本番用に固定する2点が未確定。矢印はユーザー確認済みのトラック横断を含む概略動線で、現地の障害物を自動検知する機能はない。

## 集合区分による表示

`assemblyGroups()` が全12種目の集合区分を生成する。個人の人数や人形は表示せず、集合範囲とA〜Hの記号を図に重ね、同じ記号の一覧に対象と並び方を示す。

- リレー：本部側とバックストレート側の2区分に走順を列挙する。
- 式典・準備体操：学年ごとの3区分。
- 大縄・棒引き・玉入れ：組ごとの8区分。
- 騎馬戦：各組の紅白待機区分。総当たりの試合切替に合わせて全区分が移動する。
- 部行進・部対抗リレー：部別に整列する集合範囲をまとめて示す。部ごとの精密座標は推測しない。

個人の集合位置は `personalGroupId()` の返す区分に必ず含まれる。`assembly-groups.test.ts` で全種目・学年・組・走順の対応を照合し、`guide-modes.test.ts` で全体用に個人操作が出ないことと個人用に他区分も残ることを検証する。


2026-09-12集合区分への変更を検証：全285テスト・Lint・型・ビルド成功。`/me?id=<学籍番号>` で種目別のリレーと大縄の全体区分表示、個人のリレーで自分と他区分の同時表示を確認。390px幅でも一覧が縦に並び横はみ出しなし。外周円弧に沿うテントの位置と接線方向の向きを目視確認した。


## 通しアニメーション（2026-09-13追加）

個人用・全体用に `GroundPlayback` を追加。全12種目の区分を常時保持し、集合→競技→交代→退場を連続表示する。リレーは3学年×8組×全走順。部行進は21部を一般部員とリレー出場者に分ける。部対抗はパフォーマンス1周→女子4×200m→男子①4×200m→男子②4×200m。

R8原資料の追加読取：スウェーデンは100/100/200/200/300/400m、混合は1〜6走100m・7〜8走200m。大縄は8の字と全員跳びを各30秒練習・1分30秒本番。棒引きは女子→男子の6回戦（1〜2棒保持、3〜4走り出し、5〜6選抜2人）。騎馬戦は各コートで女子→男子を4試合、続いて大将戦女子→男子。元文書や担当者名は保存しない。

玉入れは合同24名チーム・4試合・前後半1分と円内要員交代を模式再生。ただし学年別退場の文と矛盾し、円の割当も不明なので説明に要確認と表示。部対抗の男子①サッカー重複は原表通りで要確認。陸上ハンデ位置、大将戦の精密隊形、閉会式後の出口は推測しない。部別の一般退場先も所属未入力のため生徒席方向まで。

全区分一覧・●競技中／○待機を併用。初期停止、タブ非表示で一時停止、場面の選択・前後・速度・シークに対応。モーション低減時は手動切替。勝敗・所要時間は再現せず、図の時間は短縮した説明用。

`playback.test.ts` で全種目の連続性、全区分維持、全走者、周回、交代・残留を検証する。
