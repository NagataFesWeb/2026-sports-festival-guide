# 集合場所・競技の流れ（2026-10-01更新）

2026年10月2日（金）の体育祭で、生徒がいつ・どこへ行くか、競技がどう進むかを確認する案内。学籍番号の出場表と最新の演技台帳を使う。

## 画面

`/me?id=<学籍番号>` は自分の当日案内をプログラム順に表示する。開会式・準備体操・閉会式、対象学年の全員競技も含む。各カードに集合タイミング、場所、出場枠、開始予定、持ち物をまとめる。個人招集CSVの時刻・場所・補足を優先する。

- **集合場所**：自分の生徒席→集合場所→競技位置の2段階の矢印。自分の区分は色と「自分の区分」の文字で示す。ほかの区分の凡例は折りたたむ。
- **競技の流れ**：集合→競技→交代→退場を再生。個人の学年組・走順に対応する区分へ「自分」を表示する。部活動の所属は推測しない。
- リレー系4種は反時計回り。集合は「走前」、走り終えた後はゴール／バトン位置側の「走後」へ移動し、退場指示を待つ。本部が下の図では、走前は本部側の左・反対側の右、走後は本部側の右・反対側の左。両区分を再生図に表示する。
- 初期停止。演出OFF・OSの動きを減らす設定でも「流れを再生」を押せば再生できる。再生/一時停止・静止した前後の場面を表示し、場面選択・速度・シーク・最初へ・区分一覧は折りたたむ。
- 立体/真上は表示、回転・ズームは詳細操作へ。GPS・位置合わせ・glTF保存のUIは除去。
- 自分以外の競技は下部の「ほかの人の案内を確認する」から開く。番号検索と競技別全体図を使える。
- 独立した `/ground-guide` も維持。幅375px/1280pxで確認する。図の配置・時間・順位は実測/実競技の再現ではなく説明用。

|---|---|
| 開会式 | 本部を向いて右から1→2→3年、各学年右から1→8組。出席番号順2列。開会宣言・国歌・挨拶・宣誓 |

| 大縄 | 1年生、部対抗終了15分後（更衣後）。ロープ東側で2列。8の字→全員跳び、各30秒練習・1分30秒本番 |
| 棒引き | 2年生、大縄後。女子→男子を3セット、全6回戦。1〜2は棒保持、3〜4は4m開始線から、5〜6は選抜2人。交代時は人の後ろを通る |
| 騎馬戦 | 3年生。総当たり女子4試合→男子4試合。白2・4・6・7組固定、紅1・3・5・8組時計回り。大将戦は女子→男子、各応援合戦→騎馬でコート内側一周→試合 |
| 閉会式 | 騎馬戦後いったん生徒席、放送で開会式と同じ位置へ。男女各1列 |
