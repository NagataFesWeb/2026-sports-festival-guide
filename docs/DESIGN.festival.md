# DESIGN（表画面）— 爆裂（モック v2 の移植）

> 対象: `/`・`/login`・`/me`・`/ranking`・`/admin/*`。裏画面（`/casino/*`）は [DESIGN.underground.md](DESIGN.underground.md) で、両者は色・書体・部品を共有しない（切替演出だけが例外）。
> **唯一の出典は `docs/mockup/体育祭サイト モック v2 爆裂.dc.html`**（ブラウザで開くと見られる。`support.js` が必要）。この DESIGN.md はその CSS をトークンとして写したもので、迷ったらモックの CSS をそのまま使う。独自のアレンジは加えない。
> トークンの実体は `src/app/globals.css`（`@theme` の `--color-om-*`・`--font-om-mincho` と `.om-*` クラス）。管理画面だけは `src/components/admin/admin.css` の `.adm-*` クラス（同じトークン変数を参照）で組んでいる。

## 題材（1文）
体育祭当日にスマホで開く**リソグラフ印刷のポスターのような公式サイト**。黒とクリーム地に蛍光ピンク・黄・青を刷った「パンク／ポスター」の見た目で、「今どの種目で、自分はいつどこに集合か」を一瞬で見せる。得点は当日非公開で、閉会式で一斉に公開する。

## シグネチャ（モック通りに作る）
1. **ヒーロー**: 黒地に `NAGATA NAGATA…` の超薄字（`rgba(245,242,233,.055)`）を敷き詰めてスクロール連動で動かし、Shippori Mincho の巨大な「滅」と蛍光ピンクの「！」、赤青の `mix-blend-mode:screen` グリッチ二重像、`rotate(-3deg)` / `1.2deg` の 2 段マーキー、黄色のマーキー帯「♡ 青春爆裂愛してる ★」。
2. **ステッカー**: `border:2px solid #111` ＋ `box-shadow:6px 6px 0 #111` のカードを `rotate(-4deg)` などで少し傾ける（「BAKURETSU」）。
3. **黒地の透かし見出し**: 各ページ上部の黒帯に「MY PAGE」「FINAL」を巨大な薄字（Anton）で敷く。

## 画面構成（モック v2 の順番。変えない）
- `/`: ローディング（「NAGATA ENERGY / 青春 充填中」バー）→ ヒーロー → ABOUT（コピー＋ 960 PLAYERS / 8 TEAMS / 12 PROGRAMS ＋ 斜線の写真枠＋ステッカー）→ 爆裂 8 CLASSES（色スウォッチ＋クラス名。**公開前は「得点は最終集計後に公開」**、公開後は得点と順位を同じ枠内に出す）→ 爆裂 PROGRAM（12 枚のカード。番号・状態タグ 終了/進行中/次/予定・名称・英語名・時刻・場所・MORE →。押すとモーダルで詳細）→ TIMETABLE（黒地、08:45 → 14:20 の縦タイムライン。進行中は赤、次は黄）→ CTA「自分の招集案内を見る」→ フッター「NAGATA **79**TH・2026」。
- `/login`: 黒帯＋学籍番号入力（モックに独立画面は無いので、CTA と同じ語彙で 1 枚に収める）。
- `/me?id=`: 黒帯（MY PAGE 透かし、学籍番号、「2年1組・1組 紅蓮」）→ 自分の招集案内（左ボーダー色・時刻・種目・場所・タグ）→ 出場種目 → 種目別 招集案内（すべて/式典/トラック/フィールド/部活動 のチップ → アコーディオンで 招集開始目安・集合場所・持ち物・対象・招集隊形図）。
- `/ranking`: 黒帯（FINAL 透かし）→ 精算前は破線枠の「LOCKED」カード → 精算後はランクカード一覧。
- `/admin`: 黒帯「COMMITTEE CONSOLE / 実行委員 管理画面」＋ログイン中メール → 白地カードのセクション（進行の遅延・前倒し、結果確定、得点公開、CSV、赤枠黒地の FINAL SETTLEMENT）。既存のタブ機能はすべて残し、見た目だけこのトーンに載せる。

## 隠しボタン（モック通り）
- フッターの「79」の文字そのものがボタン。**1.4 秒以内に 5 回連続タップ**で発火。タップごとに文字色が `rgba(245,242,233,.75)` → `#C8E6A6` → `#FF2020` と段階的に変わり、WebAudio で `420 + n×120` Hz の短いビープを鳴らす（音は表側でここだけ）。
- 発火後: 暗転 → `SYSTEM ERROR` → `AUTHORIZED PERSONNEL ONLY` → ネオンで `NAGATA UNDERGROUND` が点灯 → `/casino/enter`。合計 2〜4 秒。`prefers-reduced-motion` では即遷移。

## 避けると決めたもの
- 前版（集中線・生成り紙・Dela Gothic・Yuji Syuku）の部品と `fes-*` トークンは廃止。混在させない
- 角丸・ぼかし影・グラデーションボタン・絵文字アイコン
- 表側に「カジノ」「ポイント」「ベット」の語、トランプ・チップのモチーフ

## 不変条件
- 表画面に `lcd-*`・`cab-*`・`ug-*` を混ぜない。逆も同じ
- 得点・順位は `settings.scores_published_at` が null の間は表側に一切出さない（管理画面は常に見える）
- 隠しボタンは「79」5 連打だけ。可視のアイコンや導線は置かない
- タップ領域 44px 以上、入力欄 16px 以上、375px 幅で横スクロールを出さない（マーキーは `overflow:hidden` の中で動かす）
- 色だけで状態を表さない（状態タグは文字を併記）
- 得点・順位・招集案内・時刻はサーバーの値をそのまま表示する。遅延（`delayMin`）の加算もサーバー側で行う
