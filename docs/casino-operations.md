
## 通信障害時

ベットと借入返済は15秒で待機を打ち切り、入力内容と再送識別子を保持します。再試行すると同じ操作として扱い、通信が切れる直前に保存済みでも二重に引いたり借りたりしません。送信結果が未確認の間は取消操作を止めます。同期中に返った古い残高で新しい操作結果を上書きしません。

取消はベット削除と返金を一度に保存するため二重返金しません。ログアウトに失敗した場合は画面に再試行案内を出し、ログアウトしたように見せません。共用端末はログアウト完了を確認して次の人に渡してください。
